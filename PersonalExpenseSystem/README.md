# Sistema di Gestione delle Spese Personali e del Budget

Applicazione basata su console per la gestione e il monitoraggio delle spese giornaliere e dei budget mensili, sviluppata in Python con database relazionale SQL (SQLite).

## 🛠️ Requisiti per l'Esecuzione
* **Interprete:** Python 3.x (consigliata versione 3.8 o superiore)
* **Database:** SQLite3 (incluso nativamente nella libreria standard di Python)
* **Librerie standard utilizzate:** `sqlite3`, `os`, `datetime`

## 🚀 Istruzioni per Eseguire il Programma

### 1. Prerequisiti
Assicurati di trovarti nella cartella principale del progetto (`PersonalExpenseSystem`). Il database verrà inizializzato automaticamente al primo avvio eseguendo lo script SQL fornito.

### 2. Comando di Avvio
Apri il terminale di sistema, posizionati nella cartella `src` ed esegui il seguente comando esatto:

```bash
python main.py
```
