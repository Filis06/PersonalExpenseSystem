# Personal Expense System

Sistema di Gestione delle Spese Personali e del Budget realizzato per l'esame di Fondamenti di Informatica (L-8).

## Requisiti per l'esecuzione
- Python 3.x
- Libreria standard `sqlite3` (inclusa nativamente in Python)

## Istruzioni per l'avvio
1. Aprire il terminale del computer.
2. Posizionarsi nella cartella corretta dei sorgenti: `cd src`
3. Eseguire il comando: `python3 main.py`
